# Favilla Candle – E-Commerce Platform

Favilla Candle, mum ürünlerinin çevrim içi satışını gerçekleştirmek için geliştirilmiş bir e-ticaret uygulamasıdır.

## Kullanılan Teknolojiler

- **Frontend:** React, TypeScript, Vite
- **Backend:** Node.js, Express.js
- **Veritabanı:** PostgreSQL
- **Admin Panel:** React

## Özellikler

- Ürün listeleme ve detay sayfaları
- Sepet yönetimi
- Sipariş oluşturma
- Kullanıcı giriş sistemi
- Yönetim paneli
- Ürün ve sipariş yönetimi

## Kurulum

Her klasörde ayrı ayrı:

```bash
npm install
npm run dev
```
